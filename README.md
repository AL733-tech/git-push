**IoT-Based Bulb Control System**: 

This project demonstrates an Internet of Things (IoT) based bulb control system that allows users to turn a bulb ON and OFF remotely using a Wi-Fi-enabled microcontroller.

The system showcases the fundamentals of IoT, including wireless communication, remote device control, and automation.

**Features**:
-Remote bulb control
-Real-time ON/OFF switching
-Wi-Fi connectivity
-Simple and user-friendly operation
-Low-cost hardware implementation
-Components Used
-ESP32 Microcontroller
-Relay Module
-Light Bulb
-Jumper Wires
-Breadboard
-Power Supply

**How It Works**:
The microcontroller connects to a Wi-Fi network.
User commands are sent through a web interface or IoT platform.
The relay receives the control signal from the microcontroller.
The relay switches the bulb ON or OFF based on the received command.

**Project Objectives**:
-Demonstrate IoT-based remote control.
-Understand communication between hardware and network devices.
-Develop practical skills in embedded systems and automation.

**Technologies Used**:
-Arduino IDE
-C/C++
-ESP32
-Wi-Fi Communication
